# BlasterZone Plugins

Revenge plugin suite by theone. Voice mods, fakes, and quality-of-life — all as proper installable Revenge plugins.

## Install

Add this URL in Revenge → Settings → Plugins → Repositories:

```
https://nrxd.github.io/blasterzone-pluginsi-/dist/repo.json
```

Or install the BlasterZone IPA (auto-registers the repo on first launch).

## Plugins

| Plugin | Description |
|--------|-------------|
| **Fake Deafen** | Appear deafened, still hear everything |
| **Fake Mute** | Appear muted, still transmit audio |
| **Gain Boost ⚡** | Mic boost up to 700% (God tier) |
| **Desktop Spoof** | Spoof gateway identify as Windows/Mac |
| **Silent Typing** | No typing indicator when you type |
| **Message Logger** | See deleted and edited messages |
| **ClearURLs** | Strip tracking params from links |
| **Image Zoom** | Pinch-to-zoom images |
| **Fake Nitro** | Use emoji from any server |
| **AMOLED** | True black theme |
| **Show Hidden Channels** | See locked channels |
| **Read All Button** | Mark all servers read |
| **No Typing Indicator** | Hide others' typing |
| **Always Animate** | GIFs always animated |
| **Online Friend Count** | See online friend count |

## IPA

Download `BlasterZone.ipa` from GitHub Actions → Artifacts, sign with KSign.
